> **系列标签：** `MDStudio` · `限制` · `VIP` · `免费试跑`

MDStudio 能在浏览器里把分子结构变成 Lammps 输入，但它**不是**无限算力的集群节点。用之前先分清两类操作：**轻量级任务**（画、看、管文件、力场转换等）几乎不占共享算力；**重量级任务**（力场生成、装盒、测试模拟、结构变换等）会排队、吃墙钟、卡原子数——**平台主要限制的是后者**。

本文写清：哪些算重活、限额数字怎么挡、免费与 VIP 差在哪。逐步怎么点：[Quickstart：从画分子到测试模拟](M01-Quickstart从画分子到测试模拟.md)；界面地图：[MDStudio功能与界面总览](M03-MDStudio功能与界面总览.md)。

## 一、Studio 里的两类任务

下表按**算力体感**划分，**不区分免费 / VIP**（谁能点哪些 Tab，见第二节）。

| 类型      | 典型操作（界面 Tab / 动作）                                                               | 体感                     | 限制侧重点                          |
| ------- | ------------------------------------------------------------------------------- | ---------------------- | ------------------------------ |
| **轻量级** | **孤立分子**绘制；**周期分子**、**粗粒颗粒**生成；**分子仓库**浏览 / 预览 / 导入；工作区浏览、重命名、删除、文本预览 / 编辑；上传与下载；结构预览；**力场转换** | 秒级交互，一般不占任务队列          | 工作区容量、预览 / 编辑大小、VIP 门控（上传·导入·编辑）、预览结构规模      |
| **重量级** | **力场生成**（含电荷）；**搭建盒子**；**测试模拟**；**结构变换**                                     | 表单下方出现任务状态、可能排队；数秒～数分钟 | **单分子原子数、装盒总原子、测试原子数、任务墙钟、并发** |

一句话：**轻量级**偏结构编辑、预览、文件与仓库、力场格式转换；**重量级**是力场生成、装盒、测试模拟、结构变换。

适合用来装输入与测试，不适合长时间生产 MD、GB 级轨迹在线存、或取代课题组集群。生产轨迹请下载后走本机 / 集群：[分子模拟工作平台搭建](../../在线资源/01-技术文档/T01-分子模拟工作平台搭建.md)、[本地与集群文件传输](../../在线资源/01-技术文档/T09-本地与集群文件传输.md)、[集群与 SLURM 简明教程](../../在线资源/01-技术文档/T10-集群与SLURM简明教程.md)。

当前墙钟与规模是共享机房的保护线；后续会按反馈扩容或对接高性能集群。使用中的需求、限额疑问，或界面 / 任务异常与疑似 bug，欢迎经官网 [联系我们](https://www.molsimulx.com/contact_us/) 反馈；有效 bug 反馈我们会按情况回馈积分。

## 二、账号与权益（谁能点哪些功能）

登录后按会员档位开放 Tab 与额度。**免费**可跟练 Quickstart 主流程里的重量级任务（规模更紧）；更大体系、以及部分轻量级功能（周期分子、粗粒颗粒、力场转换、上传 / 导入等）需 **VIP**。

### 2.1 功能开关

| 能力 | 轻/重 | 免费 | VIP |
|------|-------|------|-----|
| 登录、打开工作室 | — | ✅ | ✅ |
| **孤立分子**绘制；仓库浏览 / 预览 | 轻 | ✅ | ✅ |
| 工作区浏览、重命名、复制、移动、删除、下载 | 轻 | ✅ | ✅ |
| 工作区**文本预览**（双击打开） | 轻 | ✅（只读） | ✅ |
| 工作区**编辑 / 保存 / 另存为** | 轻 | ❌ | ✅ |
| **周期分子**、**粗粒颗粒**生成；**力场转换** | 轻 | ❌ | ✅ |
| 仓库**导入**、工作区**上传** | 轻 | ❌ | ✅ |
| **力场生成** | 重 | ✅（电荷见下） | ✅ |
| **搭建盒子**、**测试模拟** | 重 | ✅（规模见第三节） | ✅ |
| **结构变换** | 重 | ❌ | ✅ |

### 2.2 电荷方法（重量级：力场生成）

免费可选 **mmff94**、**am1-bcc**、**none**。**resp**、**eqeq** 需 VIP。

### 2.3 免费档怎么用

跟 [Quickstart：从画分子到测试模拟](M01-Quickstart从画分子到测试模拟.md)：**画乙醇 → 力场 → 装盒约 10 个分子（总原子约 90，远低于免费装盒 ≤1000）→ 测试模拟**。结构用孤立分子画板生成；**不要依赖上传、仓库导入，或在线改 `pack.inp`**（编辑保存需 VIP，见 [MDStudio资源管理器](M04-MDStudio资源管理器.md)）。

## 三、重量级任务的规模与时间

限额分两层：**会员档位**（免费更紧）与**机房硬顶**（VIP 接近下表「VIP / 机房」列；有效值常为 `min(档位, 机房)`）。表单、SMILES、保存结构、以及手改过的 `pack.inp`，都会按**当前内容**重算——**改文件名和内容不能绕过**。

### 3.1 规模上限（主要卡重量级）

| 类别 | 主要挡谁 | 免费 | VIP / 机房（当前） | 超出时 |
|------|----------|------|-------------------|--------|
| **单分子原子数** | 力场生成、结构变换等；以及绘制 / 生成结构保存到工作区（含**粗粒颗粒**的珠数） | **≤ 50** | **1000** | 直接拒绝启动该步 |
| **装盒总原子** | Packmol（阶段 ②） | **≤ 1000** | **10 万** | 缩小个数；VIP 略超时可能给 `run_packmol.sh`；阶段 ③ 另有 **2×** 有效上限硬顶（免费 **2000** / VIP **20 万**） |
| **测试模拟原子** | 测试模拟 | 机房硬顶 **5000**（免费通常先撞上装盒 ≤1000） | **5000** | 无法启动测试 |
| **`.ff` 拓扑行数** | 力场生成 / 装盒写 Lammps（Web 硬拦） | 同机房 | 键 **6000** / 角 **30000** / 二面角 **50000** / 离面角 **20000** | 拒绝或改 `topo=none` |
| **工作区总容量** | 轻量也会碰 | **50 MB** | **200 MB** | 清理文件 |
| **上传单文件** | VIP 上传（轻量 IO） | 不可上传 | **20 MB** | 失败 |
| **文本预览** | 资源管理器双击打开 | **≤ 20 MB**（免费只读） | 同左 | 过大无法打开；改用本机编辑或下载 |
| **在线编辑保存** | 资源管理器 | ❌（仅 VIP） | **≤ 2 MB** 可保存；2–20 MB 只读预览 | 开通 VIP，或本机改完再上传 |
| **单目录条目** | 资源管理器 | **50** | 同左 | 清理或新建子目录 |
| **3D 预览** | 右侧可视化 | 原子 **10 万**；电荷着色 **1000**；轨迹最多 **200** 帧 | 同左 | 超限跳过 3D / 降级着色 / 抽帧 |

> **Tips（免费）：** 乙醇约 9 原子 × **10** ≈ 90 原子，远低于免费装盒 **总原子 ≤1000**。手改 `pack.inp` 的 `number` 再跑 Packmol，会按 `pack.inp` **重算**总原子——但免费档**不能**在线保存编辑，需 VIP 或下载到本机改。

> **Tips（VIP）：** Packmol 略超在线上限时，可能给出 `run_packmol.sh` 供本地跑完回传 `simbox.xyz`；**远超 10 万**请 [联系我们](https://www.molsimulx.com/contact_us/)。AM1-BCC 原子数 **>50**、RESP **>10** 时会「写集群脚本 + 挂起 → 上传 `.out` 续跑」（需上传权限），不是简单禁算。

### 3.2 墙钟与排队（重量级共用）

| 任务 kind | 墙钟（秒） | 场景 |
|-----------|------------|------|
| `msxff` | **300** | 力场生成 |
| `msxtrans` | **60** | 结构变换 |
| `msxbox_packmol` | **60** | 装盒 ① 写 `pack.inp` |
| `packmol` | **300** | 装盒 ② 跑 Packmol |
| `msxbox_lammps` | **60** | 装盒 ③ 写 Lammps |
| `lammps_test` | **300** | 测试模拟 ② |

超时会杀进程树；半成品**不**自动删除。排队等待**不计入**墙钟。

并发队列（当前机房）：全站同时运行 **3**、每用户运行+排队合计 **1**、全站排队长度 **20**。同一用户前一个重活没完，下一个会等。界面若显示其它数字，以线上配置为准。

## 四、安全与习惯

- 勿向公共在线环境上传**未发表、涉密**数据。
- 大轨迹、完整生产输出放本地 / 集群，勿把工作区当硬盘。
- 正式模拟：下载 `data.lmp` / `in.lmp` 后改到本机或集群。

| 现象                                | 可先检查                                                |

| 测试模拟点不了                           | 缺 `data.lmp` / `in.lmp` / `in.test.lmp`（及需要时的 `pair.lmp`），或超测试原子上限 **5000**               |

## 小结

1. 先分清轻重（与是否 VIP 无关）：**轻**含绘制、仓库、文件 IO、力场转换等；**重**为力场生成、装盒、测试模拟、结构变换——主要限制在重量级。
2. **免费**可跑通孤立分子绘制 → 力场（mmff94 / am1-bcc / none）→ 装盒 → 测试（单分子 ≤50、装盒总原子 ≤1000、工作区 50 MB；无上传 / 导入 / 在线编辑保存）。
3. **VIP** 单分子约 1000、装盒约 10 万、工作区 200 MB，并开放周期分子、粗粒颗粒、力场转换、结构变换、上传、导入与文本编辑；阶段 ③ 另有 **2×** 装盒硬顶（免费 2000 / VIP 20 万）。
4. 限额按**当前文件内容**统计，不以文件名为准；电荷超 AM1-BCC 50 / RESP 10 会改写远端脚本续跑；测试模拟机房硬顶 **5000** 原子。
5. 长跑与生产请下载后走集群；扩容与产品需求可 [联系我们](https://www.molsimulx.com/contact_us/) 反馈。
6. 遇到 bug、界面异常或文档与产品不一致，也欢迎 [联系我们](https://www.molsimulx.com/contact_us/) 反馈；有效 bug 反馈我们会按情况回馈积分。
