> **系列标签：** `知识文档` · `分子模拟` · `MLFF` · `MolSimulX`

经典力场把势能写成「键 + LJ + 库仑」；AIMD 每一步都做电子结构，准但贵。夹在中间的一条路越来越常见：先用 DFT（或更高精度方法）算一批构型的能量与力，再训练一个**可求导的替代模型**，之后用这个模型驱动长时、较大体系的 MD——这就是**机器学习力场**（machine learning force field, **MLFF**），文献里也常叫 **机器学习原子间势**（machine learning interatomic potential, **MLIP**）或 **神经势**（neural network potential, NNP）。

你会卡在哪？名字太多：GAP、SNAP、DeepMD、SchNet、NequIP、Allegro、MACE、CHGNet、MatterSim……像在背手机型号。其实多数工作只是在回答同一件事：

> **怎样把「原子局域环境」编码成数字，再映射到能量与力，且尽量遵守物理对称性、尽量少数据、尽量能接进 MD 引擎？**

[高精度力场与机器学习势](K05-高精度力场与机器学习势.md) 把 ML 势放在「算得准」梯子上点到为止；[第一性原理分子动力学与核量子效应](K26-第一性原理分子动力学与核量子效应.md) 说明 AIMD 如何为 MLFF 产数据。**本文展开方案谱系与代表工作**，帮你认门派、看边界，而不是教某一家软件的安装命令。

## 一、MLFF 在流水线里站哪一格？

```text
DFT / AIMD / 高精单点
        │  能量、力、（应力）
        ▼
   训练 / 主动学习
        │  得到势模型
        ▼
  ASE / LAMMPS / … 里跑 MD、优化、振动
        │
        ▼
   结构、热力学、动力学量（仍要验证）
```

| | 经典全原子力场 | AIMD | MLFF-MD |
|--|----------------|------|---------|
| 势能从哪来 | 人手写公式 + 参数表 | 每步电子结构 | 拟合 QM 的替代模型 |
| 拓扑 | 常固定键表 | 可不依赖键表 | 多数**不依赖**固定键表 |
| 速度（粗比） | 最快（大体系） | 最慢 | 介于二者：远快于 AIMD，常慢于简单 LJ/AA |
| 精度上限 | 函数形式 + 拟合域 | 所选电子结构方法 | **≈ 训练标签的级别** + 外推风险 |
| 典型翻车 | 参数域外「自信地偏」 | 太贵、采样不够 | **分布外「自信地错」** |

一句话：MLFF 不是「免费的 DFT」，而是 **把已付过的 QM 账单摊到很多步 MD 上**；账单质量与覆盖范围，决定你能跑多远。

> **Tips：** 评估时除了能量 RMSE，更要看**力**、径向分布 / 相行为，以及故意构造的分布外构型。只报训练集漂亮分数，不够写进 Methods。

## 二、共同骨架：局域环境 → 能量 → 力

现代主流 MLIP 多采用 **原子能量可加**：

$$
E = \sum_i E_i(\text{邻域}_i)
$$

力是能量对坐标的（自动）导数。这样自然满足：平移不变；换原子编号不影响总能量（若实现正确）。

还要尽量满足：

| 对称 / 约束 | 含义 |
|-------------|------|
| **旋转等变 / 不变** | 整体旋转体系，能量不变，力跟着转 |
| **置换对称** | 同种原子交换，结果不变 |
| **截断半径** | 只看邻域内原子 → 可线性扩展到大体系；**长程静电**有时要另接 |

差别几乎都在：**邻域怎么写成特征（描述符）**，以及 **用线性回归、核方法还是神经网络** 去拟合 $E_i$。

## 三、方案谱系（先认路线，再认名字）

### 1. 四条主路线

| 路线 | 核心想法 | 代表（举例） | 直觉强弱项 |
|------|----------|--------------|------------|
| **A. 手工/半手工描述符 + 回归** | 先算 SOAP、矩、ACE 等特征，再高斯过程 / 线性 / 核岭 | GAP、SNAP、部分 ACE 流程 | 数据效率高、可解释性相对好；特征工程与截断要懂 |
| **B. 深度势（对称函数 / 嵌入）** | 端到端网络，输入距离等，输出原子能 | Behler–Parrinello、DeepMD、SchNet | 工程与材料应用多；深度网络要更多数据与调参 |
| **C. 等变消息传递 / 高阶张量** | 图网络在节点间传信息，并严格处理旋转等变性 | NequIP、Allegro、MACE | 近年力精度与数据效率讨论多；算力与实现更重 |
| **D. 「基础 / 通用」材料势** | 在超大元素与结构库上预训练，开箱推多种晶体 | CHGNet、MACE-MP、MatterSim、SevenNet 等 | 降低「每个体系从零训」成本；对你的化学仍要验证，溶液/软物质未必覆盖 |

这些路线有交叉（例如 ACE 描述符可接线性或非线性；MACE 也可当「通用预训练」用）。表是地图，不是互斥分类法。

### 2. 和「反应力场 / 极化力场」别混

| 名称 | 是不是 MLFF |
|------|-------------|
| ReaxFF 等 | **否**（经验键级势，可断键） |
| Drude / AMOEBA | **否**（物理极化模型） |
| DeepMD / MACE 等 | **是**（数据驱动拟合 QM 势能面） |
| 用 ML 修正经典力场残差 | **灰区**（常叫 Δ-ML；仍属 ML 势家族） |

## 四、代表工作（按历史与门派）

下面按「你在文献里最常撞见的名字」组织。年份与「第一篇」不必背；记住**各自解决什么瓶颈**即可。

### 1. 描述符 + 核 / 线性方法

| 工作 | 要点 | 常见语境 |
|------|------|----------|
| **Behler–Parrinello NNP**（约 2007 起） | 对称函数描述邻域 + 神经网络原子能；ML 势现代叙事的重要起点 | 方法史、教学 |
| **GAP**（Gaussian Approximation Potential） | SOAP 等描述符 + **高斯过程**；不确定性可辅助主动学习 | 材料、高精度势 |
| **SNAP** | 基于矩的描述符 + 线性/核回归；LAMMPS 材料社区常见 | 与经典 MD 引擎对接 |
| **ACE**（Atomic Cluster Expansion） | 系统的体展开式描述符；可线性拟合，也可作网络输入 | 可解释性、系统完备性讨论 |

**何时先想这条线：** 数据不多、想要不确定性、或材料组已有 SOAP/ACE 工具链。

### 2. 深度势与工程化 MD

| 工作 | 要点 | 常见语境 |
|------|------|----------|
| **Deep Potential / DeePMD-kit** | 局域嵌入 + 深度网络；强调可扩展 MD、与 LAMMPS 等对接 | 凝聚态、反应、地质与能源材料等应用多 |
| **SchNet** | 连续滤波卷积式深度势；早期深度势代表 | 方法论文、分子数据集 |
| **ANI** 等 | 有机小分子方向的神经势族 | 有机化学、构象 |

**DeepMD 为什么常被点名：** 不是「唯一最准」，而是 **训练–部署–大规模 MD** 工程闭环相对成熟，论文与开源代码都多。代价是：主生态偏 **Linux + CUDA**；Apple Silicon 上不如 PyTorch+MPS 路线顺手。

### 3. 等变图网络与高阶消息传递

| 工作 | 要点 | 常见语境 |
|------|------|----------|
| **NequIP** | $E(3)$ 等变消息传递；强调数据效率与力精度 | GNN-MLIP 转折点之一 |
| **Allegro** | 强调可扩展到更大体系的等变架构 | 大规模原子体系 |
| **MACE** | 高阶等变消息传递（与 ACE 思想有联系）；材料/分子文献高频 | ASE 计算器、预训练权重、部分 LAMMPS 路径 |

**直觉：** 早期网络若只吃标量距离，要靠数据「学会」旋转怎么影响力；等变架构把对称性**建进模型**，往往更省数据、力更稳——但实现与算力更重。

> **Tips：** MACE 在 Mac（Apple Silicon）上可用 PyTorch **MPS** 做小体系试跑；NVIDIA **CUDA** 仍是训练与生产级推理的主流。DeePMD 生产路径更盯 CUDA 集群。

### 4. 预训练「通用」材料势（基础模型向）

| 工作 / 产品向名称 | 要点 | 使用心态 |
|-------------------|------|----------|
| **MACE-MP** 等 | 在 Materials Project 等大规模数据上训的通用 MACE | 晶体、无机材料的快速起点 |
| **CHGNet** | 同时面向能量、力、磁矩等；材料结构优化/MD 常用 | 开箱试晶体，再决定是否微调 |
| **MatterSim、SevenNet、ORB** 等 | 同类「通用材料势」赛道，更新快 | 以官方文档与许可为准，选前看元素与任务覆盖 |

**适用：** 无机晶体、电池材料、催化表面等「MP 式」化学空间。  
**慎用：** 任意有机溶液、聚合物、复杂界面——预训练没见过的局域环境，仍会自信输出错误力。

### 5. 主动学习与工作流框架（不是又一个网络名）

名字常和上面模型绑在一起出现：

| 概念 | 作用 |
|------|------|
| **主动学习 / 迭代采构** | 跑 MD → 找不确定或失败构型 → 补算 QM → 再训 |
| **委员会模型 / 不确定性** | 多模型分歧大 → 优先算这些点 |
| **微调（fine-tune）** | 在通用势上用你的体系数据接着训 |

没有主动学习，只「一次性拟合当前数据集」，容易在反应坐标、高温、缺陷处翻车。

## 五、和 MD 引擎怎么接？

| 接入方式 | 典型 | 适合 |
|----------|------|------|
| **ASE Calculator** | MACE、CHGNet、许多 PyTorch 势 | 优化、振动、短 MD、原型验证 |
| **LAMMPS pair / ML-IAP** | DeepMD、部分 SNAP/ACE、部分导出势 | 与经典 MD 工作流、大体系、集群脚本一致 |
| **专用 MD 引擎** | 各势自带或社区插件 | 跟文档走 |

对「先经典装盒再切 MLFF」的流程：几何（Packmol）可复用；**进入 MLFF 后通常不再使用经典键角二面角拓扑**，避免与 ML 总能量重复受力。最小输入往往是：**元素 + 坐标 +（周期）晶胞**。

硬件直觉：

| 平台 | 现实 |
|------|------|
| **NVIDIA GPU（CUDA）** | 训练与生产级推理首选 |
| **Apple Silicon（MPS）** | MACE 等 PyTorch 势可小体系开发；非 DeePMD 主战场 |
| **纯 CPU** | 能冒烟，难当长时间、中等以上体系的生产手段 |

## 六、怎么选：一张问题表

| 你的情况 | 更常先想 |
|----------|----------|
| 无机晶体、想快速优化 / 短 MD，暂无自有大数据 | 通用势（CHGNet / MACE-MP 等）+ **严格验证** |
| 特定材料 / 反应，要追你组的 DFT 设置 | 自建数据集 + DeepMD 或 MACE 等 + 主动学习 |
| 数据很少、要不确定性 | GAP 一类，或带不确定度的工作流 |
| 只要有机溶液热力学，已有可靠 AA 力场 | **先别上 MLFF**；经典 AA 往往更合适 |
| 反应中心小、环境大 | 考虑 [QM-MM思想](K27-QM-MM思想.md) 或「环境经典 + 热点 ML/QM」 |
| 已有 AIMD 短轨迹，想拉长采样 | AIMD 产数据 → 训 MLFF → MLFF-MD（见 [K26](K26-第一性原理分子动力学与核量子效应.md)） |

**精度梯子（与 K05 一致，落到 MLFF）：**

```text
经典 AA →（不够）→ 极化 / 多体 / Reax
                →（要 QM 势能面、又要长度）→ 体系专用 MLFF
                →（想开箱试材料）→ 通用预训练势 + 验证
                →（机理基准）→ AIMD / 高精电子结构
```

## 七、常见误区

| 误区 | 更稳妥的理解 |
|------|----------------|
| 「换了 MACE/DeepMD 就比 GAFF 全面更准」 | 只在你的观测吃 QM 势能面、且数据覆盖时才成立 |
| 「通用势 = 万能力场」 | 预训练化学空间外会翻车；溶液尤其危险 |
| 「MLFF 不需要验证」 | 要比能量、力、结构量，最好再加分布外压力测试 |
| 「有力输出就等于守恒、稳定」 | 看积分设置、截断、数值精度；长轨迹要查能量漂移 |
| 「训练 RMSE 低 = 能发 Nature」 | 还要看任务相关的物理量与外推；数据泄漏见 [K28](K28-机器学习数据基础.md) |
| 「Mac 上能 import 就能当集群替代」 | 开发可以；生产级训练/长 MD 仍看 CUDA 资源 |

## 八、小结

1. **MLFF/MLIP** = 用数据拟合 QM（等）势能面，再驱动 MD；精度上限≈标签方法，风险在**外推**。  
2. 方案先分四条线：**描述符回归、深度势、等变 GNN、通用预训练势**；名字是线路上的车型。  
3. **GAP/SNAP/ACE**、**DeepMD/SchNet**、**NequIP/Allegro/MACE**、**CHGNet/MACE-MP** 等，优先记痛点与生态，而不是背年份。  
4. 工程上分清 **ASE 试跑** vs **LAMMPS 生产**；硬件上 CUDA 为主，M4/MPS 适合部分 PyTorch 势的小体系开发。  
5. 选题顺序：先问观测量是否吃这层精度 → 有无数据 / 能否主动学习 → 再选模型家族。  
6. 与经典、AIMD、QM/MM 是**工具箱协作**，不是互相消灭。

## 常见问题

**Q：MLFF、MLIP、NNP 是三个东西吗？**  
A：常指同一类「机器学习原子间势」。MLFF 偏「当力场用」；MLIP/NNP 偏方法称呼。读论文看上下文即可。

**Q：一定要从零训练吗？**  
A：材料晶体可先试通用预训练势；特殊化学、反应路径、溶液体系，更常需要自有数据或微调。

**Q：和 ReaxFF 怎么选？**  
A：已有可靠 Reax 参数且问题匹配 → 反应力场仍可；要贴近特定 DFT 势能面、又有算力产数据 → MLFF。二者都要验证能垒与路径。

**Q：长程静电怎么办？**  
A：许多短程 MLIP 只保证截断内；离子晶体、电解质有时需长程修正或混合方案。选题时查该模型是否显式处理电荷 / 长程。
