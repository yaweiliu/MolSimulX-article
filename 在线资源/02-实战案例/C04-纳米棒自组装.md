> **系列标签：** `实战案例` · `自组装` · `纳米棒` · `粗粒化` · `MDStudio`

各向异性纳米颗粒（棒、盘、螺旋……）一挤到一起，就可能从无序液体走向向列、层状甚至晶体——这就是**自组装**。实验里常靠耗尽吸引、溶剂挥发或外场；模拟里要先有一个**能代表颗粒形状**的粗粒模型，再在可控压力 / 密度下看有序化。

重叠球（overlapping-sphere）模型把一根棒拆成一串互相重叠的刚性珠子：形状好控、相互作用好写，也方便在轨迹里只跟「原点 + 取向」重建整根棒。本站早期研究笔记用纯 Python 造棒、写 data、跑 Langevin 压缩；**本篇改成以 MDStudio 为主路径**：在「粗粒颗粒」里摆棒、「搭建盒子」里装多根，再接 LAMMPS 与分析 Notebook。

| 量 / 步骤 | 主路径 | 在哪做 |
|-----------|--------|--------|
| **单棒几何** | 一维 `rod`，link = rigid | **MDStudio 粗粒颗粒** |
| **多棒初始构型** | 装盒写出 `data.lmp` | **MDStudio 搭建盒子** |
| **动力学** | Langevin + 刚体 + 加压压缩 | **LAMMPS**（`in.lmp`） |
| **有序化判据** | 密度 / 压力、向列序 $S_2$、可视化重建 | **轨迹后处理**（Notebook） |

**本文讲**：重叠球棒的几何与相互作用约定 → MDStudio 造棒并装盒 → `in.lmp` 关键设置 → 怎么跑 → 与 `simul_analysis.ipynb` 对齐的分析流程。配套输入与分析脚本见文末资源包（生产轨迹可自行跑完再分析；正式长跑可不进包）。

概念背景见 [粗粒化与加速模型](../00-知识文档/K04-粗粒化与加速模型.md)、[对比单位与无量纲化](../00-知识文档/K15-对比单位与无量纲化.md)、[序参量与相变](../00-知识文档/K20-序参量与相变.md)。MDStudio 操作详解见 [粗粒颗粒](../../在线工具/00-MDStudio/M13-MDStudio粗粒颗粒.md)。

> **和旧笔记的关系：** 素材来自研究笔记 *Dynamics simulations of self-assembly of nanoparticles*（Tutorial I–VII）与棒状有序化示例。旧文用手写 `Rod` 类、`atom_style hybrid bond dipole` 记取向；本篇用 MDStudio 出几何，取向从每根棒的端珠向量重建——少依赖 dipole 包，分析更贴「粗粒颗粒」产物。

## 一、模型与方法背后的数学

本节先钉死「棒怎么表示」「珠子怎么相互作用」「加压看什么」；下一节起再动手在 MDStudio 里摆珠子。

### 1. 重叠球棒：几何

一根棒状颗粒用 **spherocylinder** 描述：圆柱段长 $L$、直径 $D$，两端各一半球。重叠球模型把它写成沿轴线等距分布的 $N$ 个直径为 $D$ 的球，球心落在长为 $L$ 的线段上：

$$
\Delta \ell=\frac{L}{N-1},\qquad
\mathbf r_i=\mathbf r_0+i\,\Delta\ell\,\hat{\mathbf u},\quad i=0,\ldots,N-1
$$

| 符号 | 含义 | 本例建议 |
|------|------|----------|
| $L$ | 轴线上端到端长度（不含端帽时的圆柱段习惯与文献一致） | `length = 5`（对比单位） |
| $D$ | 球直径（≈ LJ $\sigma$） | $\sigma=1\Rightarrow D=1$ |
| $N$ | 珠数 | `number = 11` → $\Delta\ell=0.5$ |
| $\Delta\ell$ | 相邻球心距 | 宜 $\le 0.5D$，减轻珠间「凹槽」伪效应 |

MDStudio「粗粒颗粒 · 一维 rod」正是按 length / spacing / number 联动摆珠；link 选 **rigid** 时不写键，留给 LAMMPS `fix rigid` 当刚体。

> **Tips：** 旧笔记里 type 1 / 2 两颗「特殊球」挂 dipole 记 $\mathbf u,\mathbf v$。本篇**不依赖 dipole**：每分子按珠序取首尾（或首与次）球心，差向量归一化即得棒轴 $\hat{\mathbf u}$。需要任意形状时，再考虑双轴 / 两向量方案。

### 2. 珠–珠相互作用：软排斥（伪硬球）

文献算例常用连续伪硬球 Mie 势（截断平移），避免硬球 MD 的事件驱动，又逼近硬核：

$$
U(r)=A\,\varepsilon\left[\left(\frac{\sigma}{r}\right)^{50}-\left(\frac{\sigma}{r}\right)^{49}\right],
\qquad
A=50\left(\frac{50}{49}\right)^{49},
\qquad
r_\mathrm{cut}=\frac{50}{49}\sigma
$$

同一根棒内的珠子**不**算对势（`neigh_modify exclude molecule/intra` + `fix rigid`）。温度取对比单位 $k_BT/\varepsilon=1$，质量 $m=1$，时间单位 $\tau=D\sqrt{m/(k_BT)}$。

| 项 | 本例约定 |
|----|----------|
| **单位** | LAMMPS `units lj`（生产脚本） |
| **势** | `pair_style mie/cut`，$n=50$, $m=49$ |
| **刚体** | `fix rigid … molecule` |
| **热浴** | Langevin；$T=1$ |
| **压浴** | Berendsen；先低压平衡，再加压压缩看有序化 |

MDStudio 粗粒颗粒默认写出的是单 type **LJ**（对比 $\sigma=\varepsilon=1$），便于预览与冒烟。**正式自组装生产**以资源包 `in.lmp` 的 Mie + `units lj` 为准；装盒得到的坐标与分子分组仍直接沿用。

### 3. 动力学与加压路径

每颗珠子受力 = 保守力 $F^C$（Mie）+ 摩擦 $F^F=-(m/\gamma)\mathbf v$ + 随机力 $F^R$。棒作为刚体整体平动 / 转动。教学路径：

```text
低密度 / 低压平衡（各向同性）
        → 缓慢加压（或升密度）
        → 向列 / 层状 / 晶体（视长径比与压力）
```

本例先跑通「能装盒、能刚体 Langevin、能看序参量随压力变化」；完整相图扫描留给加长生产。

### 4. 有序化怎么定量：向列序 $S_2$

棒轴单位向量 $\hat{\mathbf u}_i$ 的二阶向列序参量（标量）：

$$
S_2=\left\langle\frac{3}{2}(\hat{\mathbf u}_i\cdot\hat{\mathbf n})^2-\frac{1}{2}\right\rangle
$$

其中 $\hat{\mathbf n}$ 为瞬时指向子（最大本征向量）。$S_2\approx 0$ 近似各向同性；$S_2$ 明显升高标志向列有序。层状 / 晶体还需密度调制、层间距等（Notebook 先把 $S_2$ 与 $P$–$\rho$ 钉牢）。序参量总图见 [序参量与相变](../00-知识文档/K20-序参量与相变.md)。

公式既定，下面在 MDStudio 里造一根棒、再装成一盒。

## 二、搭模型（MDStudio）

目标产物：工作区里的 **`data.lmp`**（多根刚性重叠球棒）。单棒几何来自「粗粒颗粒」，**不经过**力场生成。

| 项 | 本例取值 | 说明 |
|----|----------|------|
| **单棒** | `rod`，$L=5$，$N=11$，link = **rigid** | $\Delta\ell=0.5$，$\sigma=\varepsilon=\mathrm{mass}=1$ |
| **规模（教学）** | 约 **100–200** 根（资源包定死具体数） | 先短跑出图；正式相图再加大 |
| **状态点** | $T=1$（lj），低压平衡后加压 | 与 `in.lmp` 一致 |
| **原子类型** | 单 type（粗粒颗粒默认） | 同质珠；分子 id 区分不同棒 |

### 1. 粗粒颗粒：造一根刚性棒

1. 打开 [MDStudio粗粒颗粒](../../在线工具/00-MDStudio/M13-MDStudio粗粒颗粒.md)。  
2. 选 **一维** → 几何 **`rod`**。  
3. 按表填写（名称可用 `rod`）：

| 参数 | 取值 |
|------|------|
| length | `5` |
| number | `11`（spacing 会自动成 `0.5`） |
| axis | `x` |
| sigma / epsilon / mass | `1` / `1` / `1` |
| link | **rigid** |

4. 「预览结构」：勾选右侧 **实际尺寸** 可核对珠子按 $\sigma$ 接触；默认球比例 0.3 更易看清骨架。  
5. 「保存结构与力场」→ 得到 `rod.mol` + `rod.ff`。

> **Tips：** `rod` 与 `chain` 几何相同；`chain` 默认成键。自组装刚体棒务必用 **rod + rigid**，不要用 chain。

### 2. 搭建盒子：多根棒装入周期盒

1. 打开 [MDStudio搭建盒子](../../在线工具/00-MDStudio/M11-MDStudio搭建盒子.md)。  
2. 物种选 `rod`（上一步的 `.mol` + `.ff`）；分子数填本例规模。  
3. 边长先略松（低密度各向同性），交给后面 Berendsen 加压收盒；或按笔记习惯用略放大的六角晶格密度估边长。  
4. 走完「生成 Packmol → 运行 Packmol → 写出 `data.lmp`」。

本例**不必**改 `pack.inp`（与 C01 板—水—板不同：这里没有 `fixed` 墙）。

> **注意：** Packmol 装的是刚体棒的初始坐标；棒与棒可能有轻微重叠，LAMMPS 开头用短最小化 / 软势预平衡即可。生产脚本里用 `fix rigid … molecule` 把同一 `mol` 的珠锁成刚体。

> **Tips（有序初态 / 晶体 + 其他组分）：** 若先用 [结构变换 · 分子晶体](../../在线工具/00-MDStudio/M10-MDStudio结构变换.md) 排出规则棒阵，再把 `_trans.xyz` 当物种、`个数=1`（常配 `fixed`），并在该行填 **atoms_per_mol = 单棒珠数**，③ 生成 Lammps 时会按块切开 molecule id。溶剂等其它组分仍 `atoms_per_mol=0`。细节见 [搭建盒子](../../在线工具/00-MDStudio/M11-MDStudio搭建盒子.md) §3.1。本例主路径仍用「单棒 × N」随机装盒。

### 3. 冒烟（可选）与下载

在 [MDStudio测试模拟](../../在线工具/00-MDStudio/M12-MDStudio测试模拟.md) 可对默认 LJ 做极短冒烟，确认拓扑与能量不炸。**正式有序化路径**请用资源包 `in.lmp`（`units lj` + Mie + Langevin + Berendsen），不要把冒烟轨迹当自组装结果。

在 [MDStudio资源管理器](../../在线工具/00-MDStudio/M04-MDStudio资源管理器.md) 打包下载 `rod.mol` / `rod.ff` / `data.lmp`。也可直接用文末资源包已写好的构型与脚本。

## 三、`in.lmp` 关键设置

整条流水线（与资源包 `in.lmp` 对齐；细节以包内文件为准）：

```text
读 data.lmp（多棒）
  → Mie 软排斥 + exclude 分子内
  → fix rigid（按 molecule）
  → Langevin（T=1）+ Berendsen 压浴
  → 低压平衡 →（可选）加压压缩
  → dump：每棒代表珠坐标（及可选全部珠）→ 分析用
```

下面只抠和自组装直接相关的几处。

### 1. 单位、原子风格与势

```lammps
units           lj
dimension       3
boundary        p p p
atom_style      full          # 以资源包为准；需 mol 分组

pair_style      mie/cut  1.02040816327
pair_modify     shift yes
pair_coeff      * *  1.0  1.0  50  49

neigh_modify    exclude molecule/intra all
```

| 要点 | 说明 |
|------|------|
| `units lj` | 与对比单位教学一致；时间步典型 `0.005` |
| Mie 50–49 | 伪硬球；截断 $(50/49)\sigma$ |
| `exclude molecule/intra` | 同一棒内珠子不算对势，交给刚体约束 |

若你从 MDStudio 下的 `data.lmp` 是 `real` 单位头，生产前需按资源包说明**改用 lj 版 data**，或使用包内已转换的 `data.lmp`——不要混用两套单位。

### 2. 刚体 + Langevin + 压浴

```lammps
fix     rigid all rigid/small molecule
fix     lang  all langevin 1.0 1.0 1.0 ${myrand} zero yes
fix     press all press/berendsen iso ${mypress} ${mypress} 5.0
```

| 阶段 | `mypress` | 目的 |
|------|-----------|------|
| 平衡 | 低（如 `1.0`） | 得到各向同性参考 |
| 压缩 | 升至更高（如扫到 `3.0`） | 诱发向列 / 更高有序 |

通信截断按棒长留余量（旧笔记：`comm_modify cutoff ≈ L/2 + 0.1`），避免刚体跨处理器出错。

### 3. 输出：给分析留「可重建」的信息

每根棒不必全程 dump 全部珠子。推荐至少输出：

- **thermo / 自定义 log**：步数、$T$、$P$、$L_x L_y L_z$、棒数  
- **代表珠**（如每分子第 1 颗 + 末颗，或质心 + 取向向量）：用于算 $S_2$ 与重建可视化  

资源包 dump 字段与 Notebook 读取约定写在 `simul_analysis.ipynb` 顶部；改 dump 时两边一起改。

## 五、Notebook 分析

本地在资源包目录打开 `simul_analysis.ipynb`，**自上而下依次运行**（顺序对齐 C02 / C03：先 thermo，再轨迹，再序参量，最后汇总）。

`_helper_functions.py` 与 C02 / C03 尽量共用通用读 log / 画图接口；棒取向与 $S_2$ 放在本例专用模块（如 `_nematic_order.py`）。

### 1. 热力学：密度与压力

从 thermo 画 $P(t)$、$\rho(t)$、边长。加压段应看到密度上升；有序化常伴随压力–密度曲线斜率或平台变化（教学上先定性，不强求完整相界）。

### 2. 从珠坐标重建棒轴

对每一帧、每一个 `mol`：

$$
\hat{\mathbf u}=\frac{\mathbf r_{\mathrm{end}}-\mathbf r_{\mathrm{start}}}{|\mathbf r_{\mathrm{end}}-\mathbf r_{\mathrm{start}}|}
$$

必要时把坐标 **unwrap** 后再做差，避免棒跨盒被折断。旧笔记用 dipole；本篇用端珠，与 MDStudio 单 type 产物一致。

### 3. 向列序 $S_2(t)$

用全体 $\hat{\mathbf u}_i$ 构 $Q$ 张量、取最大本征值得 $S_2$。对照：

| 阶段 | 期望（定性） |
|------|----------------|
| 低压平衡 | $S_2$ 在 0 附近涨落 |
| 加压后 | $S_2$ 系统性抬高（向列） |

### 4. 可视化重建（可选）

用代表珠 + $\hat{\mathbf u}$ 与单棒模板（`rod.mol` 几何）旋转平移，重建整根重叠球棒再着色（按簇 / 按 $|\hat{\mathbf u}\cdot\hat{\mathbf n}|$）。旧 Tutorial VII 的 Plato / VMD 路线可作延伸；本例 Notebook 以 Matplotlib / 简单 3D 为主，降低环境依赖。

### 5. 结果汇总

Notebook 末尾写入 `summary_self_assembly.csv`（平均密度、压力窗口、$S_2$ 平台值等），便于对照样例。

## 六、讨论

### 1. 本例结果算不算「自组装成功」？

教学验收优先看三条：

| 检查 | 期望 |
|------|------|
| 刚体 + Langevin 不炸 | 能量 / 温度平台合理 |
| 加压后密度上升 | Berendsen 生效 |
| $S_2$ 随压力抬高 | 向列有序出现 |

完整「各向同性 → 向列 → 层状 → 晶体」相序依赖长径比、势、加压速率与体系尺寸；短教学跑通 $S_2$ 抬升即可。正式报相界需有限尺寸扫描与更长采样（见 [有限尺寸效应](../00-知识文档/K18-有限尺寸效应.md)、[统计误差与块平均](../00-知识文档/K17-统计误差与块平均.md)）。

### 2. 什么时候该换模型 / 换路径

| 场景 | 建议 |
|------|------|
| **只练 MDStudio 粗粒几何** | 停在第二节 + 冒烟即可 |
| **硬核棒相行为（对标文献）** | 用本例 Mie + lj + 刚体 |
| **耗尽吸引 / 棒–聚合物** | 另加聚合物珠或有效吸引；不在本文展开 |
| **螺旋、盘、壳** | 仍用粗粒颗粒其它几何；分析取向定义要改 |
| **全原子纳米棒** | 走孤立分子 / 力场生成，不是本篇重叠球路线 |

## 常见问题

**Q：为什么不继续用 dipole 记取向？**  
A：MDStudio 粗粒颗粒是单 type 珠串，不生成 dipole。端珠向量对单轴棒足够；少一个 PACKAGE 依赖，和装盒产物一致。

**Q：MDStudio 的 `.ff` 是 LJ，生产却用 Mie？**  
A：`.ff` 服务预览与冒烟；生产脚本显式写 Mie 系数。几何与分子分组来自 `data.lmp`，对势以 `in.lmp` 为准。

**Q：`fix rigid` 和 link=rigid 是一回事吗？**  
A：MDStudio 的 link=rigid 表示**不写键**；LAMMPS 里仍要 `fix rigid` 才在积分时保持刚性。只装盒不写 `fix rigid`，珠子会按对势各自动。

**Q：珠数 $N$、间距 $\Delta\ell$ 怎么选？**  
A：经验上 $\Delta\ell\le 0.5D$。$N$ 太稀，棒侧面凹槽伪效应大；$N$ 太密，白费计算。本例 $L=5$、$N=11$ 是教学默认。

**Q：可以只 dump 代表珠吗？**  
A：可以，而且推荐。分析与可视化用模板重建即可；全珠 dump 磁盘大、对 $S_2$ 无必要。

## 小结

1. **模型**：重叠球棒用 $N$ 个球逼近 spherocylinder；珠间软排斥 Mie；棒内刚体。  
2. **MDStudio**：粗粒颗粒 `rod` + rigid → 搭建盒子装多根 → `data.lmp`。  
3. **`in.lmp`**：`units lj` + Mie + `fix rigid` + Langevin + Berendsen；低压平衡后加压。  
4. **分析**：端珠建 $\hat{\mathbf u}$ → $S_2(t)$ + thermo；可选模板重建可视化。  
5. **验收**：不炸、加压变密、$S_2$ 抬升；完整相图需加长与扫参。
