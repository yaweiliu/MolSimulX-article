```bash
cd /path/to/MolSimulX-article
```

## 文章状态（仅两种）

| 本地 `status` | 含义 | `publish.py` |
|---------------|------|--------------|
| `draft` | 写作 / 审阅中 | 跳过（除非 `--force`） |
| `reviewed` | 可同步到 WordPress | CREATE / UPDATE |

本地**不要**再写 `published` / `revised`。上线与否以 WP 为准；改稿后保持 `reviewed`，再跑脚本更新。

```text
draft ──审完──► reviewed ── publish.py ──► WP（默认 draft，可 --publish）
                 ▲                              │
                 └──────── 改稿后仍用 reviewed ───┘
```

## 日常：发一篇

```bash
python tools/publish.py --list

# YAML 里 status: reviewed 后
python tools/publish.py T01 --dry-run
python tools/publish.py T01 --write-back-id

# WP 后台预览 → 配 erphpdown → 点「发布」
# 或脚本直接上线（慎用）：
# python tools/publish.py T01 --write-back-id --publish
```

`T01` 可换成任意编号；也可用 `--id T01`、`--pick`、`--file 某文件名.md`。

## 日常：批量 / 增量

```bash
# 指定多篇
python tools/publish.py T02 T03 T04 --write-back-id

# 全库 reviewed
python tools/publish.py --all-reviewed --write-back-id

# 增量（推荐改稿后）：新 reviewed / 内容有变 / 互链回填
python tools/publish.py --sync-plan
python tools/publish.py --sync --write-back-id

# 一次性补历史灰链
python tools/publish.py --refresh-links --write-back-id
```

### 配图（可单独跑；`publish.py` 默认会自动执行）

`sync_article_images.py`：按正文图片引用找源图 → 归档到 `images/articles/…/original/` → 转 `web/*.webp`。

```bash
python tools/sync_article_images.py T01 --rewrite-md --prune-sources
python tools/sync_article_images.py T01 --dry-run
```

| 参数                                             | 作用                                          |
| ---------------------------------------------- | ------------------------------------------- |
| `T01` / `--id` / `--file` / `--pick` / `--all` | 选文章（同 publish）                              |
| `--rewrite-md`                                 | 把 md 引用改成规范 `web/*.webp` 相对路径               |
| `--prune-sources`                              | WebP 成功后删项目内散落重复源图（保留 `original/` / `web/`） |
| `--keep-sources`                               | 不删散落源图（与上互斥）                                |
| `--dry-run`                                    | 只报告，不写盘                                     |
